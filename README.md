# Brainwave

Brainwave is a futuristic-themed website built with **React**, **Tailwind CSS**, and **Vite**. It features smooth hover effects, interactive SVG shapes, and a sleek purple color palette that gives it a modern, cutting-edge look.

## 🚀 Features

* **Parallax Effects:** Smooth parallax scrolling powered by react-just-parallax.
* **Futuristic Design:** Elegant and modern UI with purple color aesthetics.
* **SVG Shapes:** Interactive and eye-catching SVG elements.
* **Hover Effects:** Smooth and engaging hover transitions.
* **Fast and Optimized:** Built with Vite for blazing-fast development and optimized build.
